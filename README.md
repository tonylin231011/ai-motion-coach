# AI Motion Coach

React + TypeScript + Vite 的手机摄像头健身原型。姿态识别和动作计数在浏览器本地完成，支持深蹲、俯卧撑、平板支撑、俄罗斯转体、反向卷腹、哑铃弯举、靠墙静蹲，并有中文语音、训练记录和每日热力图。

## 在另一台电脑继续开发

1. 安装 Node.js 20.19+ 或 22.12+、Git。
2. 克隆本仓库，在项目目录运行 `npm ci`。
3. 运行 `npm run dev`，按照终端显示的本地地址在电脑浏览器打开。摄像头需要授权。
4. 修改后运行 `npm run build` 检查编译和打包。

本地开发地址使用 `localhost`。若要用手机访问电脑开发服务，需要 HTTPS 或发布到已有的 CloudBase 地址，因为手机浏览器通常只在安全环境允许摄像头。

已发布的测试版：https://nanbuqu-dashboard-d0drnae5202324-1433064673.tcloudbaseapp.com/ai-motion-coach/

训练记录保存在使用者当前浏览器的本地存储中，不随 Git 仓库同步。仓库中包含运行所需的 MediaPipe 模型、WASM 和中文语音文件；本地 CloudBase 登录信息、缓存和构建产物不会提交。

要把记录带到 Fitness OS，请在**实际训练过的手机和原浏览器**打开“训练记录”，点击“导出全部训练记录”，保存 JSON，再到 Fitness OS 的“配置后台 → 训练记录导入”选择该文件。导出包含所有动作及原始记录编号；俄罗斯转体标明左、右每侧各计一次，平板保持时长保留毫秒值。换浏览器打开本页不会自动找回原浏览器里的记录。

当前算法和后续事项见 [NEXT-STEPS.md](NEXT-STEPS.md)。俄罗斯转体在真实手机上的计数稳定性仍需继续验证。

## 哑铃弯举（已发布）

选择“哑铃弯举”，手机固定在正面略偏侧，拍清肩、肘和手腕；无需全身或脚入镜。先自然放下手臂，再弯起并控制放回。每只手各计一次，双手同步一轮共两次；镜头、总结和历史显示左手／右手次数（指人体左右，画面为镜像）。仅看清一侧时只计该侧。支持同步和交替，不要求固定节拍；可见完成动作的幅度偏小或节奏偏快会提示，仍计入完成量。

历史和 JSON 保存 `curlCountUnit: "arm_reps"`、`armCounts: {left, right}` 和逐次 `side`。Fitness OS 的配套导入器保留这些事实，按原始编号去重；旧版导入器需更新才能接收此新动作。不能识别哑铃重量、肌肉发力或认证完整动作质量；不会补写重量或 RPE。

`npm run test:curl`（Node.js 22.18+ 或 24）验证合成关键点的计数与防抖。真人手机与不同机位的识别率仍需实测，不能以合成测试替代。
