# GPT Action 配置包（只读）

## 给 ChatGPT 的前置约束：生产链路优先

此接口正在生产使用，Muse 每天依赖它同步训练数据。保持现有手机上传与 Muse 读取链路正常的优先级，高于本次 GPT 接入实验。本次正常方案是服务端零改动，只调用，不改造。

1. **接口不变**：现有路径、参数、Bearer 鉴权、游标分页和响应结构保持原样。Action 只描述并调用现有能力，不为解决接入或响应大小问题修改服务端。
2. **密钥不变**：不得重置、轮换、替换或覆盖现有读写密钥及其哈希；读写哈希必须不同，相同会导致全部接口返回503。不得提取 Muse 保险库秘密。若确需独立新密钥，只能提出不影响旧密钥的新增方案；当前后端不能假定支持多把只读密钥，新增支持属于服务端变更，须先获本人明确确认。
3. **数据结构不变**：不得重命名、删除既有字段或改变其含义、单位、类型；如确需扩展只能兼容性新增，且仍受服务端变更确认约束。不得删除、迁移或清空训练记录。

若认为必须修改服务端，立即停止相关变更，先列出拟改内容、影响范围、对手机/Muse的兼容性、验证及回滚方案，等待本人明确确认。一般的“继续接入”、既有部署授权或配置包制作不构成对此类变更的授权。未经确认不得执行，亦不得把服务端变更混入前端发布。

## 配置

1. 在你自己的 GPT 编辑器中，把 instructions.md 内容填入指令，启用数据分析能力以便计算和核对分页结果。
2. 新增 Action，将 openapi.json 全文粘贴进接口描述。
3. 鉴权选择 API Key，类型 Bearer。由本人在该界面填写现有的**只读**密钥。不是手机写密钥、腾讯云管理员凭据或 OpenAI API key。不要将密钥放在接口描述、聊天或知识附件中。
4. 保存为“仅自己”。此配置使用个人数据的共享服务端密钥，不适合公开发布或多人使用。
5. 使用 acceptance.md 的测试语句，在该 GPT 中完成真实调用验收。

不需要更改手机站点或 Muse，不需要退出账号、清除站点数据、重建 OAuth 或提取保险库秘密。Muse 的代理令牌未必能被 CloudBase 直接接受；如本人手头也没有直接接口接受的只读凭据，此包只能先完成结构配置，不能用未知代理地址/令牌冒充可用鉴权。本包不轮换任何密钥。

## 能力与边界

训练结束后手机现有 SyncPanel 会监听本地保存事件自动同步，失败重试、联网恢复、页面回到前台也触发同步。手机必须已配置同步且保持网络/页面运行到“云端已同步”；浏览器关闭后不能保证继续上传。

GPT 在你发起训练分析时读取最新云端副本。该指令要求每次先读取，但仍需通过实际工具调用验收；它不构成训练结束自动唤醒 GPT 或后台定时推送。Muse 原来的同步日报保持独立。

本包只提供 GET /training-sync 摘要，没有 POST/DELETE，也不公开 details 参数。当前上游每页固定100条、哈希游标排序，不支持日期筛选或单条详情。摘要含实际保持、静蹲各组、左右手计数、动作提示数量；适合趋势分析，不含每次重复的角度。

逐次明细可能超过 GPT Actions 响应限制，故不把 details=1 暴露给模型。未来如需角度级分析，应独立评估带上限的明细接口；不能仅在 schema 编造 limit、sessionId 等当前后端不支持的参数。摘要本身随组数增长也可能超限，超限即停止并报告，不能把截断数据当完整。

Action 只属于配置它的私人 GPT，不自动成为其他 ChatGPT 会话或当前 Codex 的工具。当前 Codex 能分析本人提供的文件；只有实际连接成功并暴露工具后才能声称可直接读取。
