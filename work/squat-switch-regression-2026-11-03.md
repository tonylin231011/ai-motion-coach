# 深蹲近距离准备与快捷换动作修复（2026-11-03）

基线 0777a6b。用户反馈深蹲仍须退远、切换动作入口太深。

## 根因与修复范围

深蹲仍使用 cover 裁切预览；UI 另有按躯干长度判断过近、关键点必须离画面边缘 1.5% 的额外门槛，准备稳定性还会被无关手臂移动打断。原 SquatDetector 只要求同侧髋、膝、踝可见、坐标在原始画面内，并不要求头或双手完整出现。

- 深蹲视频、骨架、提示锚点统一 contain 完整取景，实时模糊背景填充外围；仍对原始完整帧识别。
- 深蹲去掉通用躯干距离判断；准备条件与 detector 的髋/膝/踝可见度和画面边界一致，稳定性只看腿部点。缺失必要关节仍取消自动倒数，不能凭空计数。
- 训练页首屏增加吸顶原生动作选择框，全部 7 个动作直接可选；底部目录选择后回到顶部。
- 总结页顶部增加“保存并换动作”，使用原 saveDraft 保存路径，成功后回训练页；保存失败留在总结并显示错误。历史已保存总结直接返回选择动作。
- 未更改 detector、模型、识别库、记录结构、同步服务或密钥。

## 验证与限制

39 项测试通过，生产构建通过。新增无头/肩、脚踝靠边、手臂移动的深蹲自动开始与完整计数测试，以及脚踝缺失/出框/低置信度取消倒数。

隔离 Chromium（393×851）：选择框初始 y=96，滚动 900 后 y=19；可切换转体/深蹲；视频与 canvas 均 contain 且矩形完全相同 365×529.203125，共用背景视频流，无横向溢出。模拟摄像头训练完成后“保存并换动作”保留一条本地测试记录、清除已保存草稿并返回顶部，能选转体。未使用真实用户数据。

真机识别率未验收：需在用户原距离侧拍同侧髋、膝、踝，测试自动倒数和连续深蹲。合成关键点和模拟摄像头测试不能保证 OPPO 真机识别精度。现有算法仍需要同侧髋膝踝，无法在必要关节完全出画时准确计数。
